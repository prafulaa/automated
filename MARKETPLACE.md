## BlastRadius

**Review AI-generated code 10x faster. Know exactly what breaks before you merge.**

---

### Short description (200 chars)

BlastRadius maps every changed file to its downstream impact on every PR. Get a risk level + AI reviewer tip before you merge — especially useful for reviewing AI-generated code.

---

### Detailed description

BlastRadius is a GitHub App that computes the **reverse dependency blast radius** of every changed file in a pull request. On every PR open or push, it posts a single, auto-updating comment showing:

- **Which downstream files are impacted** — frontend components, API routes, and core utilities
- **A risk level** (LOW / MEDIUM / HIGH) based on impact depth, breadth, and criticality
- **An AI-written reviewer tip** — generated by Claude, telling you exactly what to watch for

**Why teams love it:**
- **30-second setup** — install, choose a repo, done. No config needed.
- **Sub-2-second response** — webhook returns instantly; analysis happens async
- **Sticky comments** — one comment per PR, auto-updated on every push. No noise.
- **Built for AI-generated code** — when your team uses Copilot, Cursor, or Claude Code, BlastRadius catches what the AI might break downstream

**Pricing:**
- **Free** — 1 public repo
- **Startup ($29/mo)** — up to 5 private repos
- **Enterprise ($99/mo)** — unlimited repos
