# Privacy Policy for BlastRadius

**Last updated: May 2026**

## What we collect

When you install BlastRadius as a GitHub App, we receive:
- Your GitHub username and organization name
- Repository names where BlastRadius is installed
- Pull request metadata (file paths changed, PR numbers)
- **We do NOT access or store your source code.** Analysis happens ephemerally.

When you sign in via GitHub OAuth, we receive:
- Your GitHub username, email, and avatar

## How we use it

- To compute dependency blast radius reports on your PRs
- To display your dashboard with repository and report history
- To manage your subscription and billing

## Data retention

- Source code analysis results are ephemeral — they are discarded after the PR comment is posted
- Report metadata (risk level, file count, timestamps) is stored for your dashboard
- You can request deletion by uninstalling the app or contacting us

## Third parties

- **Supabase** — database hosting (your data is stored in our Supabase instance)
- **Anthropic** — AI reviewer tips (only file names and categories are sent, never source code)
- **Stripe** — payment processing (if you subscribe to a paid plan)

## Your rights

- Uninstall the GitHub App at any time to stop all data collection
- Contact us at privacy@blastradius.dev to request data export or deletion
